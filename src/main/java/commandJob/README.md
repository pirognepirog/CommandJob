# Bank Recommendations Service (CommandJob)

Сервис для предоставления персонализированных рекомендаций банковских продуктов на основе анализа транзакций пользователя.

## 📋 Описание проекта

Проект реализует систему рекомендаций, состоящую из двух частей:
1. **Статические правила** (зашиты в код): Invest 500, Top Saving, Simple Credit.
2. **Динамические правила** (создаются через API и хранятся в базе данных).

Для формирования рекомендаций используется движок, который выполняет набор SQL-запросов (правил) к базе данных пользователей.

## 🛠 Технологический стек

* **Java 17**
* **Spring Boot 3.2.5** (Web, Data JDBC, Data JPA)
* **H2 Database** — основная база данных (пользователи, продукты, транзакции).
* **PostgreSQL** — вторая база данных для хранения динамических правил.
* **Liquibase** — управление миграциями схемы БД для PostgreSQL.
* **Caffeine** — кеширование результатов SQL-запросов для повышения производительности.

## 🚀 Запуск проекта

### Предварительные требования
1. Установленная Java 17.
2. Запущенный PostgreSQL.
3. Созданная база данных `rules_db` и пользователь `student` (пароль настраивается в `application.properties`).

### Настройка базы данных PostgreSQL
Выполните в pgAdmin или консоли psql от имени суперпользователя:
```sql
CREATE USER student WITH PASSWORD 'chocolatefrog';
CREATE DATABASE rules_db;
GRANT ALL PRIVILEGES ON DATABASE rules_db TO student;
